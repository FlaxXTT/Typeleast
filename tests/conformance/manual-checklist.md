# Mac 与 Windows 操作验收表

在**隔离测试账号或隔离应用状态**中进行。使用虚构文字、假凭据和可关闭的本机假整理服务。先记录应用版本、系统版本、芯片或 CPU 架构；每项分别标记通过、失败、未执行。Windows 真机验收必须在 Windows 上操作。

| 功能 | 操作和可见结果 |
|---|---|
| 首次启动 | 引导、权限提示和设置页可打开；未配置模型或 Key 时给出可理解的状态，不崩溃。 |
| 外观与语言 | 浅色、深色、中英文、最小窗口尺寸下检查首页、历史、个人偏好、扩展、设置、Beta 面板和录音条；文字可读，控件不遮挡。 |
| 录音快捷键 | 开始、停止、取消、快速重复触发；录音条显示当前整理档位或翻译目标，失去服务时能恢复。 |
| 自然与 AI 整理 | 用假模型处理虚构口述；改口与数字保留最终意思。失败时无自动粘贴，编辑窗口可以继续整理、直接使用手改内容或取消。 |
| 翻译 | 中文口述先产生可校验的中文整理稿，再翻译成自然英文；第二步失败时保留中文整理稿，界面说明失败原因。 |
| 提示词 Beta | 首轮依次确认联网、背景资料、本地范围和工作性质；连续补充三轮并纠正前一轮；问题和已确认信息更新，用户主动生成后才粘贴；取消后旧会话不能继续。 |
| 表达偏好与旧资料清理 | 使用隔离旧设置升级；确认表达示例、历史和其他设置保留，词汇和词库清理。未确认的修改不保存或外发；无法读取混存文件时保留并报告问题。 |
| 模型管理 | 默认模型可用；候选下载显示进度、取消和重试；失败保留旧模型；重启后选择一致。下载测试单独取得许可。 |
| 扩展 | 查看已安装与市场、检查本地文件、确认后安装、启用、停用及删除；无效插件不能执行代码或阻断听写。市场只在打开或刷新时联网。 |
| 历史与活动 | 搜索、重试、保留时长和清空操作符合界面提示；活动统计不保存原话。测试后检查隔离状态目录。 |
| 粘贴与焦点 | 光标换到另一窗口时不误粘贴；终端内换行处理安全；剪贴板原有内容在粘贴后恢复。 |
| 更新 | 显示版本和简短变更摘要；忙碌时不打断录音或 Beta；更新失败保留原应用及设置。正式安装、签名和权限仅在专门更新验收中检查。 |
| 隐私 | 假 Key、假听写和假上下文不出现在日志、健康接口或错误弹窗；只向选定模型发送本次所需文字。 |

可选真实验收：用公开短音频分别检查已支持的识别模型与语言；用测试模型地址验证连接、自然整理、翻译和回退。记录响应时间，但不要把少量样例当成准确率结论。不读取私人录音、真实历史或钥匙串内容。
