# Code signing policy

## Windows — SignPath Foundation

This project is applying for free code signing through SignPath Foundation.

**Status:** Pending approval. Current Windows releases are **not** code-signed yet.

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

macOS releases are not covered by this policy (they are ad-hoc signed and not notarized).

## Source code and build process

The project source code is publicly available at:

`https://github.com/FlaxXTT/Typeleast`

Windows installation packages (`TypeLeast-<version>-Windows-x64-Setup.exe` and
`TypeLeast-<version>-Windows-x64-Portable.zip`) are built from the public source repository by the
release workflow [`.github/workflows/release.yml`](../.github/workflows/release.yml), using GitHub Actions on
GitHub-hosted runners (`windows-latest`). The build scripts used by that workflow
([`apps/windows/package.ps1`](../apps/windows/package.ps1) and the Inno Setup script
[`apps/windows/installer/TypeLeast.iss`](../apps/windows/installer/TypeLeast.iss)) are kept in this repository.

Only artifacts generated by the official GitHub Actions release workflow will be submitted for code signing.
Packages built on a developer's own machine are never signed.

Releases are distributed through:

`https://github.com/FlaxXTT/Typeleast/releases`

## Code signing roles

The project has a single maintainer, who holds all three roles.

**Authors:** [`https://github.com/FlaxXTT`](https://github.com/FlaxXTT)

The project maintainer is responsible for source code changes and release maintenance.

**Reviewers:** [`https://github.com/FlaxXTT`](https://github.com/FlaxXTT)

External pull requests must be reviewed by the maintainer before merging.

**Approvers:** [`https://github.com/FlaxXTT`](https://github.com/FlaxXTT)

Each production signing request requires explicit manual approval by the maintainer.

## Privacy policy

TypeLeast has no telemetry, analytics, crash reporting or advertising, and no account. It transfers data over the
network only in these cases:

- **Speech recognition is local.** Audio is recognized on the computer by the bundled local service and never
  uploaded. Recordings are deleted after recognition, unless the user turns on keeping recordings for retries:
  they are then stored encrypted on the computer for at most 24 hours.
- **Text cleanup (optional).** If the user enters an API key for a language model provider of their choice
  (for example DeepSeek, OpenAI, Moonshot, Zhipu, Alibaba DashScope, OpenRouter, or a local Ollama), the app sends
  that provider the recognized text and the user's dictionary words; when the user turns on 参考输入框里的内容
  (off by default), also the text near the cursor and the window title. Values that look like keys or passwords
  are removed first. The provider's own privacy policy applies to that data. Without an API key, nothing is sent.
  获取列表 (list the provider's models) asks the same provider for its model list.
- **Speech model download.** When the user downloads a speech model, the files are fetched from Hugging Face
  (`huggingface.co`) or the mirror the user selects (`hf-mirror.com`).
- **Update checks.** The app reads the public release list from the GitHub API (`api.github.com`) and downloads
  update files from `github.com`. No user data is sent; GitHub receives the usual request information (such as the
  IP address and a `TypeLeast/<version>` user agent). The Windows installed version installs updates automatically
  unless this is turned off in 设置 → 服务与更新.

The local service listens only on `127.0.0.1`. API keys are stored in Windows Credential Manager (macOS: Keychain)
and are never written to logs. Settings, history and logs stay on the computer, in `%APPDATA%\TypeLeast\` and
`%LOCALAPPDATA%\TypeLeast\` on Windows.

## System changes, installation and uninstallation

The Windows installer installs for the current user only, into `%LOCALAPPDATA%\Programs\TypeLeast`, without
administrator rights. It adds a Start menu shortcut and, if chosen, a desktop shortcut. When the user turns on
登录启动 in the app, it adds a `TypeLeast` value under
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. The software makes no other system changes and installs
no drivers or services.

Users can uninstall it through Windows Settings → Apps → Installed apps (or the Start menu). The uninstaller removes
the program files, shortcuts and the start-with-Windows entry, and asks whether to also delete the user's data
(settings, history, saved recordings, downloaded speech models and the API keys in Credential Manager); a silent
uninstall keeps it. The portable version is removed by deleting its folder; its data folders are listed above.

## Release security

The project maintains its build scripts and GitHub Actions workflows in version control. The maintainer uses
multi-factor authentication for repository access.

Code signing certificates and private keys are managed by SignPath. The project does not store certificate private
keys in its repository.
