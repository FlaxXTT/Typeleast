# v1.16.0 验证记录

版本 1.16.0，Mac 构建号 7。包含 PR #17、#18 及此前未发布的提示词 Beta 与菜单修复。

## 已完成

- 服务 199 项、Mac 392 项、Windows Core 在 Mac 上 164 项测试通过，原生 DPAPI 测试明确跳过。
- Mac arm64、x86_64 编译、DMG/ZIP 打包与签名验证通过。包内 Node 固定为 24.21.0，识别引擎保持 1.13.8，复用已有的固定版本下载文件。
- Apple 芯片发布包的 Node、本地服务和默认 SenseVoice 模型在隔离状态目录启动通过，未使用真实 API Key 或私人录音。
- 四个识别模型共 28 次公开样例识别通过；详情见安全加固验证记录的补充复核。
- 本地化、脱敏、事实示例检查通过。中英文主要界面有浅色、深色及最小宽度截图抽查。
- 打包允许指定独立构建目录与下载缓存，保留原有验证文件，不覆盖此前的构建目录。

## 未验证与发布范围

本机没有 Windows 执行环境、Inno Setup 或可用托管 CI 额度；本次 Mac 发布不包含 Windows 1.16.0 安装包。Windows 1.5.0 安装包仍在原 Release 保留。

Intel 包在本机无法运行：未安装 Rosetta。不能把交叉编译或签名通过等同于 Intel 真机验证。Linux 原生执行、Windows DPAPI、Windows 真机 UI 和长期压力测试仍未完成。

更新包独立可信签名和本地服务独立身份认证未实现。加密不防止已经控制当前用户会话的攻击者；录音处理期间仍有临时明文。详细边界见 [安全加固验证记录](安全加固验证记录.md)。

本次本机更新使用现有本机证书重新签名，不导出或替换证书。安装后的版本、签名要求和进程状态另行核验，不读取私人历史或真实 Key。
