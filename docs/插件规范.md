# TypeLeast 插件规范（第 1 版）

插件只是数据，不运行任何代码。第 1 版有两种：

| 类型 | 作用 | 发给模型的内容 |
|---|---|---|
| 词库（`dictionary`） | 一组术语的正确写法 | 只有某次听写提到的词（写法相同或读音相近），随那次整理请求发送 |
| 风格（`style`） | 一段写法、格式说明，附加在标准/精简整理上 | 选中后随每次标准/精简整理请求发送；原话转写、翻译、提示词 Beta 不用 |

两种都不会多调用模型；风格说明会让每次请求多一些 token。

## 文件格式

一个 UTF-8 JSON 文件，扩展名 `.typeleast-plugin`，最大 256 KiB。不接受未知字段；超过限制直接拒绝，不截断。

```json
{
  "format": "typeleast-plugin",
  "formatVersion": 1,
  "id": "yourname.dev-terms",
  "version": "1.0.0",
  "type": "dictionary",
  "name": { "zh-Hans": "开发常用术语", "en": "Developer terms" },
  "description": { "zh-Hans": "一句话说明用途。", "en": "One line on what it is for." },
  "author": "显示名",
  "license": "CC0-1.0",
  "homepage": "https://example.com",
  "terms": ["Kubernetes", "TypeScript"]
}
```

| 字段 | 规则 |
|---|---|
| `id` | `发布者.名字`，小写字母、数字和连字符，各段 1–32 个字符。官方目录里的文件名必须是 `<id>.typeleast-plugin` |
| `version` | `主.次.修订`，不带前导零；更新时调大 |
| `name` / `description` | 中英文都要；名字最多 40 字，说明最多 200 字，单行 |
| `author` | 最多 60 字 |
| `license` | SPDX 标识（如 `CC0-1.0`、`MIT`）或 `LicenseRef-...` |
| `homepage` | 可选，只接受 `https://` |
| `terms`（词库） | 1–2000 个，每个最多 120 字，不重复（不分大小写）；不能写「听成=写法」，这类规则只能用户自己加；看起来像密钥的会被拒绝 |
| `instructions`（风格） | 非空纯文本，最多 8 KiB；看起来像密钥的会被拒绝 |

风格说明放在内置整理规则之后，并注明只影响写法和排版，不能添加事实、删掉说话内容或改变输出格式。模型不一定完全遵守；整理结果仍然经过原有的事实校验，不通过就退回原有结果。

## 在 App 里

- 左侧栏「扩展」：「已安装」和「插件市场」两个标签。
- 安装前会显示：作者、版本、许可、来源（官方目录 / 本地文件未审核）、词库的词数和示例或风格的全文，以及数据会发到哪里。可以选「仅安装」或「安装并启用」。
- 确认安装时，App 会带上所显示内容的指纹（整份内容的 SHA-256）。如果确认窗口打开后目录已经刷新、内容变了，本地服务拒绝安装（`plugin-changed`），App 重新读取目录，请用户重新查看。
- 词库按插件开关；所有启用的词库加起来最多 10000 个词。用户自己的词条优先，同一个词不重复发送。
- 风格同时只能选一个；在左侧栏整理档位下面切换（只在标准、精简整理时显示）。
- 插件文件存在本地服务的状态目录 `plugins/` 下，每个插件一个文件，加一个 `state.json` 记开关。写入先写临时文件再改名，不会留下半个文件。损坏的文件会被停用并提示，不影响听写。

## 插件市场

- 官方目录就是仓库里的 [`market/catalog.json`](../market/catalog.json)，由 `market/plugins/` 里的文件生成。官网部署时一起发布。
- App 只在打开「插件市场」标签或点「刷新」时读一次目录，依次尝试官网和 GitHub 官方地址；不走镜像，不在后台检查更新，请求里只带一个 `User-Agent`。读取失败时显示上次读到的目录和时间。
- 从市场安装的就是这份目录里的内容，不再另外下载。

提交插件见 [`market/README.md`](../market/README.md)。

## 本地服务接口

都在 `/api/voice-polish` 前缀下，需要现有的本机令牌，只给 TypeLeast 自己的 App 用。

| 方法和路径 | 作用 |
|---|---|
| `GET /plugins` | 已安装插件、开关、当前风格、损坏的文件 |
| `POST /plugins/inspect` | 请求体是插件文件；只检查、返回摘要和内容指纹 `digest`，不安装 |
| `POST /plugins?enable=1&digest=…` | 请求体是插件文件；指纹必须与检查时一致，然后安装或更新，可同时启用 |
| `PUT /plugins/{id}` | `{"enabled": true}`：开关词库 |
| `PUT /plugins/style` | `{"id": "..."}` 或 `{"id": null}`：选择风格 |
| `DELETE /plugins/{id}` | 卸载 |
| `GET /plugins/catalog` | 读一次官方目录；失败时 `ok: false` 并带上次的目录 |
| `POST /plugins/catalog/install` | `{"id": "...", "enable": true, "digest": "..."}`：指纹与当前目录里的内容一致才安装，否则 409 `plugin-changed` |

## 以后

代码型插件、企业连接器、作者自助后台和签名都不在第 1 版里。需要时出新的 `formatVersion`，旧 App 会明确拒绝不认识的版本。
