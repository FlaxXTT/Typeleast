# TypeLeast 风格插件规范

当前改版只接受风格插件；词库、读音别名和本机替换已移除。已有表达示例独立保留，插件不能访问它们或管理用户资料。

## 核心边界

插件是 UTF-8 JSON 数据，不运行代码。通过可选扩展接口向自然整理或 AI 整理提供一段写法说明，不读取文件、钥匙串、录音或历史，不自行联网或调用模型。关闭、移除或无法加载扩展时，核心整理仍工作。

选中的风格随原有生成请求发送到用户选择的提供商。需要风险完整性审查时，核心最多追加一次审查；插件不能增加调用或改变审查规则。风格只管措辞和排版，不能添加事实、删除实质条件或覆盖当前口述。

## 文件

文件名为 `<id>.typeleast-plugin`，最大256 KiB；说明最大8 KiB。只支持 `formatVersion:1`、`type:style`，未知字段、脚本、权限声明和秘密形态内容均拒绝。

```json
{
  "format": "typeleast-plugin",
  "formatVersion": 1,
  "id": "example.clear-writing",
  "version": "1.0.0",
  "type": "style",
  "name": {"zh-Hans":"清楚表达","en":"Clear writing"},
  "description": {"zh-Hans":"按主题分段，表达直接。","en":"Direct wording with one topic per paragraph."},
  "author": "Example",
  "license": "CC0-1.0",
  "instructions": "用直接、简洁的语言表达，按主题分段，不增加用户没有说的事实。"
}
```

`id` 为小写发布者与名称，用点连接；版本为语义化版本。名字与说明必须同时有中英文。作者、许可必须填写，主页可选且必须HTTPS。其余具体长度和格式限制由服务的插件验证器执行；不允许用 instructions 伪装术语映射或要求忽略系统规则。

## 安装与市场

安装前显示完整风格说明、作者、来源、许可和数据去向；用户确认的内容必须与实际安装内容一致。市场仅在用户打开或刷新时访问官方目录，使用现有来源设置，不上传用户正文。作者提交PR，维护者审查通过后合并上架；审核重点为来源、许可、数据发送和越权指令。

升级清理仅删除应用管理的词库副本及缓存，保留风格文件和选择。旧词库和v2别名文件拒绝导入，不从历史或旧缓存重新安装。已发布标签与Git历史不改写。
