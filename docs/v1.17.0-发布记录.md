# 1.17.0 发布记录

日期：2026-10-21。Mac 版本 1.17.0，构建号 9；Windows 源码版本同步至 1.17.0。

## 本次范围

- Mac 发布 Apple 芯片、Intel 的 DMG 和 ZIP，共 4 包，附现有软件内更新需要的校验清单。
- 维护者随后提供 Windows 1.17.0 安装版、便携版及校验清单，加入同一草稿。共六包；统一清单覆盖两端，另保留 Windows 原清单。原标签不移动。
- 本机确认 Windows 便携包服务与标签逐字节一致、包含原创自然整理提示词和 GPL 许可，两个 Windows 文件校验通过。Windows 打包端报告服务 218 项通过、1 项跳过，核心 539 项通过，以及 Wine 安装和内置服务启动通过；本机未重复执行 Wine 测试。现有 innoextract 1.9 不支持此安装器格式，未在 Mac 独立解包 Setup。
- 普通模式一次生成编号与自然段；Beta 支持多轮补充并由用户明确结束；设置分组、快捷模式栏和配置文件入口随本次 Mac 包交付。自然整理提示词正文未改。
- 包含已合并的网站部署与 GPL-3.0 许可变更，Mac 包内附项目许可文件。
- CI 与 Release 工作流现为手动触发。托管额度不可用，使用维护者已批准的本地验证和手动发布例外；不声称三平台 CI 通过。

## 发布与更新方式

发版分支经 PR 快进合并，在合并后的 main 创建 UTC 附注标签 v1.17.0，再手动发布到现有私有仓库。发布后通过现有 Updater 下载 Apple 芯片 ZIP、核对发布清单、使用原有本机证书重签并比对签名要求，再替换和重新启动应用。安装结果另记在本机发布目录。

## 限制

- Intel/Rosetta 运行、Windows 真机 UI 与原生 DPAPI 分支未验证。
- 未测试真实外部整理模型效果，也未做长期压力测试。
- 软件包未经过 Apple Developer ID 公证；本机更新依赖现有签名证书与私有仓库访问。
- 独立更新签名与本地服务身份认证仍是已知缺口。
- Beta 会话在服务内存中，重启会丢失未生成内容；本次更新前应结束当前录音和未完成的 Beta。
