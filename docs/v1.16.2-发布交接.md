# 1.16.2 发布交接

## 发布方式

本轮使用统一标签 `v1.16.2`，提供 Mac 与 Windows 同版本共 6 个安装包，以及软件内更新所需的校验清单。Mac 构建号为 8。Windows 源码已合并到 main，安装文件由维护者提供；Mac 在本机重新打包，不复用仍带旧提示词的 1.16.0 包。

托管 CI 没有额度，本轮按维护者已授权的例外使用本机测试、静态包检查和手动发布，不声称三平台 CI 通过。通过发版 PR 快进合并后，在 main 上创建 UTC 附注标签；保留历史 Release、标签和远程分支。

## 本机验证结果

- 服务 208 项通过，0 失败、0 跳过；Mac 392 项通过；Windows Core 在 Mac 上 525 项通过。
- Windows 应用交叉编译通过，保留既有 WFAC010 警告；不是 Windows 真机运行验证。
- 本地化检查通过：Mac 512 条翻译、570 处调用；Windows 454 条翻译、420 处调用。
- Mac Apple 芯片和 Intel 的 DMG、ZIP 均已打包。两个 ZIP 的版本与文件完整性检查通过；包内 `cleanup.js` 与源码逐字节一致，旧 `erduo-budget-typeless.js` 不存在；两个 App 完整签名验证通过。
- Apple 芯片包内 Node、本地服务与默认模型在隔离状态目录启动成功，报告当前提示词版本 `2026-10-21.1-cleanup+promptify+beta+translate`；没有读取私人历史或调用外部整理模型。
- Windows Portable ZIP 完整性检查通过，主程序版本为 1.16.2.0；整个 `service/lib` 与源码一致，包含新提示词、缺少旧提示词文件。内置 Node、字体许可和第三方说明存在；按文件名检查未发现运行状态或凭据文件。
- Windows Setup 的安装元数据为 TypeLeast 1.16.2。旧版 innoextract 不支持它使用的 Inno Setup 6.7.0；本轮临时编译支持该格式的解析工具，只解包、不运行安装程序。解出的主程序和新提示词与 Portable 逐字节一致。工具的多段文件回读校验警告由这次直接文件比较补充验证，不能当作 Windows 安装执行验证。
- 新提示词正文未改写。本轮没有读取真实 API Key、私人听写或钥匙串秘密。发布检查只涉及安装包代码、公开模型文件、隔离测试状态和签名操作。

## 未验证与保留事项

- 新提示词没有用真实整理模型试用；测试通过不能证明真实效果或排除所有数字误判。
- Windows 真机安装、界面操作、原生 DPAPI 分支、Intel 或 Rosetta 执行、长期压力测试未完成。
- 独立更新签名与本地服务身份认证仍是已知缺口，不能保证没有漏洞。
- 本机更新使用现有签名证书；不导出或替换证书，安装前告知 TypeLeast 将退出并重启。版本、签名及可安全读取的偏好项在安装后另作本机记录。
- 新提示词中与早期文本近似的段落保持维护者提供的内容；不把删除来源说明等同于原创性证明。网站部署及旧分支删除未执行。
- 提供的发布脚本默认复制旧 Mac 1.16.0 包，本次不按默认运行。原始交付文件保留；本轮临时解包及工具目录在核对最终结果后清理。此前要求保留的诊断文件不清理。
