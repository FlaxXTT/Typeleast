# 解释上下文、偏好资料与首次设置

v1.22.2 起适用于 Mac 和 Windows。没有新增模型、依赖或远端数据收集接口。

## 首次设置

新安装需先配置 API Key 和整理模型，下载并加载识别模型，授予麦克风等平台必要权限，然后完成三组真实语音练习：改口与条件、解释与正文、确认修改。只有本地识别及真实整理响应成功才记为通过；缺少模型、请求失败、回退结果或待确认名称不能完成练习。第三组还要求用户修改当前生成结果并确认。

未完成前只开放设置、权限配置、更新及退出等配置路径，阻止正常听写、粘贴上一条和历史重试。退出始终可用。此设计要求联网整理服务可用，不提供离线或模拟跳过。已存在的设置文件迁移时不强制教程，用户可主动重新学习。完成状态保存在原有设置存储中。

教程使用独立录音流程，不捕获目标输入框上下文，不访问词典或偏好、不粘贴、不写客户端历史。Mac 临时 WAV 在读入请求内存后移除，取消也会清理。Windows 使用内存音频并在请求结束清零。服务保留既有脱敏与摘要日志边界；真实录音和整理仍使用用户配置的本机识别模型及模型服务，会产生正常模型费用。

## 解释段

仅 AI 整理（内部 `concise`）生效，翻译、自然整理与提示词 Beta 不解释这些标记。用户选择固定的一组开始词、结束词，也可以在偏好资料页关闭：

- 未发布改版使用“备注／说完了”；英文为 side note / back to text。
- 原来的三组长标记仍兼容；旧选择迁移一次，已关闭者保持关闭。短标记须独立成词，引用中的标记不解释。

服务同时识别对应繁体字，容忍标记汉字间的识别空格。最多四段，每段最多 4000 字符；不接受自定义正则或执行代码。未配对、嵌套、空段或超限标记先交给非模态确认面板，允许编辑、继续口述、保留原文或取消。只有解释而没有正文时不插入，也不记为成功听写。

正文与解释分离后，正文作为用户消息，脱敏后的解释作为明确标注的数据附加到同一次整理请求。解释只能消解本次指代和名称，不能成为新的执行命令或自动带入正文的事实。事实校验以正文为依据，预算、条件和否定不能因解释段被删除。仅在一对明确名称和明确指代关系下，允许本次有证据的名称纠错；不保存成永久词典映射。输出含所选触发词或照抄完整长解释时退回正文。程序无法保证检出所有语义改写泄漏，仍需模型遵守规则。

原始识别文本在客户端历史中保留，包括解释，受原有加密和历史保留设置管理。重试保留当次选定的标记；旧记录不按后来新增的标记重新解读。

## 偏好示例

未发布改版导航为“个人偏好”，分表达示例、个人词汇、排除与高级规则。旧词典保留，不虚构训练资料。所有模式停止自动入词典；旧自动词汇及替换默认不启用。详细规则见 [个人偏好与扩展](个人偏好与扩展.md)。

示例包含实际识别原文、AI 交付文字、用户最终修改。入口为历史记录的“记录偏好”，或开启“修改学习”后已有目标输入框编辑观察器检测到的修改。后者只产生内存候选，最多五条；不自动保存、上传或确认。检测范围沿用现有前台目标窗口与有界内容规则，关闭修改学习后不观察编辑。

用户确认且确实修改后才保存，最多 100 条。Mac 使用既有历史加密密钥和 AES-GCM，Windows 使用当前用户 DPAPI；加密资料不可读时保留原数据，阻止覆盖。可逐条禁用或删除。清空历史会移除待确认候选，已确认偏好独立保存，需在偏好页删除。

客户端最多发送 20 条已确认启用的短例至本机鉴权服务，元数据限 32 KiB。服务按当前口述选择最多三条相关示例，总字符上限 6000；包含秘密形态、无关内容、名称变更或新增数值的示例不作为可复用提示。仅选中示例发到当前整理提供商，不增加模型调用。模型只参考组织和措辞，不获得修改当前事实的权限。偏好不会自动训练模型或集中上传，也不含 Key、设备路径或历史记录 ID。

## 开发验证边界

自动测试使用虚构文字、假凭据、假钥匙串／测试加密替身及隔离存储。历史布局使用离屏窗口；不是用户私人历史截图。测试源码不进入安装包。本轮不运行大规模准确率测试，也未由工具读取实际 Key、私人历史或录音。

真实麦克风、辅助功能、目标窗口粘贴及 Windows 真机操作需单独验收。已有测试通过不代表真实模型必然理解每次解释，亦不代表偏好示例属于经过人工标注的训练数据集。
