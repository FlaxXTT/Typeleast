# TypeLeast 1.4.0 检查与验证

日期：2026-10-19。检查范围为当前源码、全部本地可见 Git 历史、构建流程及使用虚构数据的测试，不读取私人历史、真实 API Key 或钥匙串内容。

## 已修复

| 问题 | 处理与验证 |
| --- | --- |
| 听写语言没有进入识别调用 | 逐次校验并传递语言；串行识别防止并发串扰；服务和识别器回归测试 |
| Windows 准备剪贴板后未重新确认前台窗口 | 发送粘贴前再次检查，窗口变化时只复制 |
| 中文显式凭据及词典内容可能进入模型请求 | 中文凭据脱敏，词典与光标上下文同样脱敏；检查实际请求负载 |
| 损坏 JSON 的解析异常可能回显请求内容 | 返回通用 400 错误；含假凭据的回归用例 |
| 原始异常和服务商信息进入诊断 | Mac 日志只保留受限状态字段，Windows 异常日志只保留类型；Mac 日志权限收紧 |
| 模型请求及客户端请求自动跟随重定向 | 禁止自动重定向，避免将请求发送到未选择的目标 |
| 接口地址可包含内嵌凭据或查询参数 | 两端拒绝此类地址，与服务约束保持一致 |
| 英文长文本挤压设置控件及统计卡片 | 设置行空间不足时上下排列；英文统计使用两列并保留数字单行 |

## 界面语言

Mac 和 Windows 支持跟随系统、简体中文、English，重启生效。中文系统默认简体中文，其余默认英语。界面语言不会改变听写语言、整理输出语言、用户内容或系统提示词正文。

Mac 438 条、Windows 200 条集中翻译，CI 检查查找键及格式参数一致性。原文提示词未修改。系统权限弹窗由操作系统控制，麦克风用途说明提供中英文资源。

## 验证方法

- 服务测试 160 项，Mac 测试 293 项，Windows 测试 102 项；脱敏、事实校验、翻译覆盖脚本通过。
- 本地真实识别器使用合成静音检查加载与语言切换；这不能代表真实口音、混合语言或识别准确率。
- Mac 使用示例数据渲染中英文页面、浅色和深色、最小宽度。渲染器使用假钥匙串，不读取真实历史。
- PR #9 的 Windows 测试、WPF 编译、三平台服务验证与安装包构建均通过；没有 Windows 真机操作结果。
- 全历史 gitleaks 初查的 9 处命中均为测试假 Key。工作目录扫描的 8 处命中也均在测试夹具中。扫描结果不等于没有所有潜在泄漏。历史文本未命中本机账号名和主机名，未发现凭据文件候选；提交身份除已知保留例外外符合 noreply 规则。

## 限制

- 未读取或核对真实 Key；如需精确比对，由维护者本人运行桌面的 GitHub 提交规则中的命令。
- 没有使用真实听写内容调用外部模型，没有进行 Windows 真机 UI 操作或公网渗透测试。
- 自动更新仍要求私有仓库 gh 登录与本机证书；Windows 没有软件内更新。
- 已知历史邮箱和标签时区例外保留，不改写历史。
- 本地历史和可选保留录音仍按现有功能保存在本机；脱敏规则无法识别所有形式的秘密。
