# 设置与提示词模式验证记录

日期：2026-10-21。范围：设置分组、快捷模式切换、普通模式默认提示词、配置文件入口、多轮 Beta。自然整理的维护者提示词正文未修改。

## 行为

- Mac、Windows 均将设置分为听写、整理、通用、隐私与权限、服务与更新；主窗口各页顶部固定显示四种整理模式。录音、整理期间禁用切换。离开尚未生成的 Beta 前要求确认。
- 普通模式一次调用完成，以编号穿插自然段，保留用户信息和核心意图；不使用角色等固定模板，不自行增加任务要求。术语只依据上下文与模型知识恢复，没有把握时保留描述，不增加联网检索。
- 普通模式正文从设置中移除。打开配置文件需风险警告、再次确认和验证码；仅在外部编辑器修改 `promptify.json`。格式错误的文件不会被入口覆盖，恢复默认保留 appendix。已有自定义 override 不被升级覆盖；需要新默认行为时可恢复默认。Windows 旧文本配置保留兼容，不删除原文件。
- Beta 每次回答均重新分析最初口述和已接受的全部回答，显示当前理解与新问题。没有新问题也等待用户明确生成；不把问题或助手建议当作用户事实。单次录音取消、静音和可恢复失败保留此前信息。
- 最终生成先独立审查；有问题时最小修补并再次审查，仍不通过则不插入。每轮分析一次调用，生成阶段两到四次调用。轮数增加会增加模型用量。
- Beta 会话只在服务内存保存；空闲十五分钟过期，总输入上限 24000 字符，同时最多二十个会话。超限拒绝本轮且保留已接受信息；同一会话并发操作被拒绝，取消后迟到结果不能恢复会话。服务重启会丢失未生成会话。
