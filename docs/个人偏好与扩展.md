# 表达偏好、风格扩展与可靠整理

本文描述 v1.23.0 后的未发布改版。不包含发版或本机安装；实际旧数据清理由安装改版后的应用启动执行，开发测试只处理隔离的虚构资料。

## 去除词汇影响

个人词汇、自动候选、持久替换、排除与启用规则、词库插件及随包术语包移除。服务忽略旧请求和配置中的词汇，不恢复旧映射。当前口述中的全称、逐字拼写、改口、解释及允许的光标上下文仍用于理解本次内容。

应用管理目录中的旧词汇密文、普通词表和候选清理；偏好混存档先保存已确认表达示例，再清除词汇状态。读取或写入失败时保留原文件、报告清理未完成。Windows设置中的旧词汇字段及密文在安全保存普通设置时移除。扩展只删除已识别的词库副本及缓存；风格、历史、录音、Key、模型权重、普通设置和用户在其他目录的原文件保留。已发布标签和Git历史不改写。

表达示例仍需用户确认，本机加密，仅相关启用示例发送给所选模型，不集中上传或自动训练。扩展保持可剥离的数据接口，只提供风格。旧历史的来源信息只读兼容，不得再次生成词汇或替换权限。

## 整理参数与审查

自然整理默认1800 tokens、temperature 0.8、单次18秒；长度估算有需要时提高输出预算，最多4096。AI整理1600 tokens、temperature 1.0、单次25秒。均使用非流式响应，等待完整结果后清理和校验。

从识别完成进入整理时，总预算60秒。上下文、生成、重试和风险审查共用时钟；暂态故障最多自动重试一次，含底层参数兼容和思考预算重试。无效Key、权限等永久错误不重复请求。客户端取消会中止对应模型请求。

有效原文达到600个Unicode字符，或不少于80个有效字符且结果少于35%，或检测到疑似条件遗漏时，最多增加一次独立审查。审查按最后确认的意思核对，不把同义改写、去重复、明确改口或重排当遗漏。问题必须引用当前依据与当前候选；无效引用不能判为审查成功。不循环修补。

标点清理独立、幂等，覆盖中文逗号与英文句号等混合残留，保护数字、版本、链接、路径、代码、列表及省略号。事实校验和审查针对最终清理后的候选，不按句子长度是否相同评分。

## 失败与接口

超时、截断、格式或完整性检查失败，不自动交付识别原文。沿用响应的 `clarification`，新增 `kind:quality`、`candidate`、`reason`；可插入的 `text` 保持空，原文在 `raw`。旧客户端也不能把草稿误当成最终正文。

复用非模态可编辑窗口，展示明确原因，提供继续整理、使用修改内容、取消。继续整理使用保留的原始识别和本次设置，无需重录；手工修改确认后直接交付，不再次强制经过模型。旧目标窗口、剪贴板与取消保护继续生效。候选只在当前操作中保留，不另写正文诊断日志。

## Beta 首轮

程序固定顺序：联网许可、背景资料名称与概述及用途、本地资料允许/禁止范围、重复性工作或创新探索。首轮确认已说明的信息，后续不重复问；允许没有资料、禁止联网、暂不确定。未答事项进入待确认。

这些答案只供生成提示词，不代表TypeLeast已搜索、读文件或获得访问权。创新性描述后续任务性质，不允许Beta补造用户需求、事实或权限。生成、审查和修订均以原始口述与全部明确回答为依据。

## 验证范围

离线回归使用虚构文本、假模型服务、测试加密替身及隔离目录。测试和SDK不进入安装包。真实模型审查质量、麦克风、目标窗口和Windows真机操作需单独验收；程序校验不能证明模型永远不遗漏。
