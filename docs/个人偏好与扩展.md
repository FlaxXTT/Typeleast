# 个人偏好与扩展

本文描述 v1.22.2 后的未发布改版。没有新增产品依赖、识别模型、联网检索或模型调用步骤。

## 处理边界

整理核心负责当前口述、改口、数字、事实和表达。个人偏好保存本人确认的表达、词汇、排除项与高级替换；扩展提供面向一类场景的数据包。扩展页负责安装和启停，不写入个人词典。

本地服务的 `personalization-policy.js` 统一筛选这些资料。`plugin-runtime.js` 只返回带来源的词、别名和风格；扩展缺失或失败时，基础整理继续。两端不再各自执行强制替换判断。

优先顺序是当前明确表达、个人排除、已确认权限、相关资料。普通个人词汇及扩展词汇是弱参考。偏好示例只用于措辞与组织，不可沿用示例事实。当前改口、否定、拼写或条件使高级替换保守跳过；通过最终事实边界检查才交付本机替换。

## 管理与迁移

个人偏好分为表达示例、个人词汇、排除与高级规则。全部模式停止自动入词典；用户修改仅产生内存待确认项，不因未修改结果而确认。只保存真实且用户确认的前后对照。

普通手工词汇默认作为参考；旧自动词汇保留但不启用。旧强制替换保留在高级区，逐条明确启用。修改规则内容会使旧许可失效，须重新启用。旧本地大小写规则同样进入高级区。记录删除与“不再参考”不同：后者跨个人、扩展及其别名暂停影响，也暂停涉及该词的高级替换。只写个人覆盖，不修改扩展原文件，扩展更新不会清除此选择；恢复时保留原启用状态。用户当前确实说出该词仍能输出。

排除最多 512 项，请求最多 128 条高级规则；记录状态有总量限制。冲突替换不会执行，替换按较长源文本优先，不连锁替换。规则不能对翻译、Beta 或失败回退结果强制改写。

## 接口与来源

既有 `/polish` JSON 可带可选 `personalization`：

```json
{"version":1,"disabled":false,"excluded":["Example"],"rules":[{"id":"rule-1","heard":"Acmee","word":"Acme","enabled":true}]}
```

既有听写 WAV 元数据在 dictionary 前缀放一份 `{ "personalization": ... }`。旧请求的 `heard=word` 不因此取得高级替换权限；只作为目标词弱参考。重复或非法策略降为关闭个性化；元数据超限时保留音频并安全关闭个性化，不截断 WAV。排除表只交给本机服务筛选，不整表发送外部模型。

响应可选 `personalization` 来源记录，包含 `disabled`、`references`、`replacements`、`blocked` 和必要的 `beforeReplacements`。参考项区分个人词汇、扩展及源 ID；这里只能证明资料被提供，不能证明模型据此改写。实际执行的本机替换另外记录。历史沿用加密及保留设置，不新增含正文的诊断日志。

历史可撤销本机替换并复制替换前文字；不自动修改已经粘贴到别的应用中的文字。仅本次关闭个性化后重试直接使用该条原始识别文字，不读新窗口上下文、不改变长期设置、不需要旧录音，会再次调用整理模型。原记录保留，重试另存历史。Beta 保留其独立流程，不提供此文本重试入口。名称确认中的本次关闭状态持续保留。

## 存储及失败

表达示例、排除及规则许可沿用本机加密资料存储。Mac 个人词汇、旧候选及旧删除记录迁入加密偏好值，使用既有 HistorySeal；新密文写入后才移除旧普通设置值。Windows 将词汇密文与普通设置放在同一个原子保存文件中，由当前用户 DPAPI 保护。旧普通设置和旧加密示例数组仍可读。加密或读取失败时保留原数据，阻止覆盖。

没有上传集中训练资料，没有自动训练模型。相关且启用的示例随原有整理请求发送到用户选择的模型。历史和词汇的加密不能防止已取得当前用户权限的恶意程序。旧版本不能读取新增的词汇密文格式，直接降级不保证兼容；本轮不安装、不改日常配置。

## 解释触发词

AI 整理使用“备注／说完了”，英文 side note / back to text。原三组长词继续识别。旧选择只迁移一次，关闭者保持关闭。短词须为独立标记，引用中的标记不生效；缺失结束词先确认。解释只提供本次上下文，不进入正文，不形成长期规则。自然整理、翻译及 Beta 不解析这些标记。

离线用三个系统合成中文音色比较候选：当前短词在三条样例中均正确识别，旧长词仅一条完整识别；“旁注”被识别成其他词，因此未采用。此结果只覆盖短小合成样例，不能证明真人口音和噪声下的准确率。六条原始 ASR 输出保存在 `service/test/fixtures/explanation-asr-v1.json`。

复现工具：`node tools/recognition/check-explanation-markers.mjs --models-dir <已有公开模型目录> --output <报告路径>`。仅在 Mac 使用系统合成语音，重新封装规范 PCM WAV，用隔离状态加载已有 Qwen 0.6B INT8，不下载权重、不切换日常模型、不播放或录麦克风。临时音频自动清理。

## 验证边界

必要回归使用虚构文字、假模型服务、隔离状态和测试加密替身。开发测试及工具不进入应用。Mac 使用离屏虚构数据检查中英文、深浅外观；Windows 交叉编译不替代真机交互。真实语音、实际钥匙串授权、外部模型对改口的理解、真实目标窗口粘贴和 Windows 真机仍需操作验收。

本地结果：服务 395/395，进程外接口 46/46，Mac 664/664，Windows 核心在 Mac 上 832/832（原生 DPAPI 项留给 Windows CI）。Windows 客户端及渲染工具交叉编译通过，仅有原有 WFAC010 提醒；Mac 四处原有编译提醒保留。本地化覆盖、事实校验及脱敏脚本通过。全历史密钥扫描的 31 个命中逐项核对为 25 个明确测试假值及 6 个设置字段误报。这不证明没有所有隐私风险。
