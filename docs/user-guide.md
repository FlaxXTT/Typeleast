# TypeLeast 使用指南

## 安装和首次听写

当前版本支持 macOS 14 或更新版本的 Apple 芯片 Mac。[下载最新版](https://github.com/FlaxXTT/Typeleast/releases/latest)

1. 打开 DMG，把 TypeLeast 拖到「应用程序」。升级时替换原来的 App，保留应用数据；发布包内带运行环境，语音模型按需下载。
2. 打开 TypeLeast，先体验免配置的示例。到最后一页选择语音识别方式，并允许麦克风和辅助功能。也可以直接进入首页以后再配置。
3. 打开「文本编辑」，按 ⌘N 新建空白文稿并点进输入区。按一次 Fn 说一句，再按一次。在文稿里看到文字，就完成了首次听写。

发布包用固定发布证书签名，尚无 Apple 公证。升级或初次安装遇到系统提示时，可核对下载页的 SHA-256 文件和应用签名说明。[签名与钥匙串迁移](CODE_SIGNING_POLICY.md)

## 选择语音识别和整理模型

打开「设置 → 模型」，分别配置两类模型。

| 用途 | 选择 | 需要什么 |
| --- | --- | --- |
| 语音识别 | 本地 MLX | 从应用内下载并启用一款本地模型。完成后识别在 Mac 上运行 |
| 语音识别 | 豆包 ASR 2.0、阿里云 Fun-ASR Realtime | 保存所选语音服务的 API Key。阿里云非默认业务空间还需填写空间 ID |
| 整理与翻译 | 支持 OpenAI 兼容接口的服务，或本机 Ollama | 选择服务商、模型 ID，按服务要求保存 API Key。远程接口用 HTTPS，本机 Ollama 可用回环 HTTP |

整理模型支持 DeepSeek、智谱 GLM、Kimi、通义千问、OpenRouter、OpenAI、本机 Ollama 和自定义接口。API 地址填写服务的基础地址。可以在模型页获取可用模型列表或测试连接。云服务可能按服务商规则计费。

基础听写只需语音识别和系统权限。可在听写设置里关掉文字整理。选中文字时，翻译快捷键会显示独立译文面板。没有选中文字时，同一个快捷键用来录音并把译文写到光标处。

### 专有名词和会议

- **Vocabulary** 可以维护热词和替换规则。替换在本机应用于听写和会议转写。豆包控制台的词表 ID 在模型页单独填写。
- **Conference** 支持本地 MOSS，也支持豆包录音文件识别模型 2.0。使用豆包会议识别时，需要配置豆包语音 API Key 和私有 TOS 桶。导入或录音结束后，应用通过该桶提交音频供服务端识别。

## Harness EQ

在「设置 → Harness EQ」从本地文件、扫描结果或公开 GitHub 链接导入选中的项目。支持将独立 Markdown Skill 保存到应用内部，以及导入含依赖的 Skill 包。MCP 可以导入为调用提示，由目标 Agent 负责实际使用。

若计划移走原文件，先核对 Harness EQ 指向归档副本。对需要依赖的 Skill，再检查归档里的 `SKILL.md` 与它引用的文件能否从同一目录体系读取。「保存来源」仍可能指向原件。可以用 README 里的提示词，让 Agent 执行这套检查并按授权移走原件。

## 隐私与本机数据

| 功能 | 数据去向 |
| --- | --- |
| 本地语音识别 | 音频在本机处理 |
| 云端语音识别 | 音频发给所选语音服务。豆包听写边录边上传，阿里云听写在停录后上传。豆包会议音频经所配置的私有 TOS 桶提交 |
| 联网整理和翻译 | 相应的转写或选中文本发给配置的模型。启用光标上下文、历史生成的场景描述或备用服务时，会按配置使用相应内容和服务 |
| 模型下载与更新 | 本地模型从应用列出的来源或选定镜像下载。更新从公网上的发布资源获取 |

macOS 使用钥匙串保存 API Key。历史正文加密保存在本机。如果开启「保留录音」，用于重试的录音会在本机加密保留约五分钟。需要使用剪贴板写入时，应用会短暂放入纯文本并恢复之前的内容。剪贴板管理器可能留有自己的记录。[隐私和更新细节](CODE_SIGNING_POLICY.md#privacy-policy)

## 常见问题

- **Fn 打开了表情或切换了输入法**。到「系统设置 → 键盘」，把「按下 🌐 键时」设为「无操作」。也可设置其他听写快捷键。
- **录不了音，或文字没有写入**。在「系统设置 → 隐私与安全性」检查麦克风和辅助功能，然后在同一个空白文稿重试。转写已完成时，可在 History 里核对并复制结果。
- **本地服务未就绪或模型下载失败**。从首页重试本地服务，或在「设置 → 模型」对目标模型重新下载。网络受限时，可以使用页面提供的镜像重试。
- **云端模型已保存却用不了**。先在对应模型区测试连接。豆包会议还需确认开通了录音文件识别，并核对私有 TOS 配置。
