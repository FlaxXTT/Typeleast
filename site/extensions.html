制作扩展

一个 JSON 文件

无需代码。

步骤

  1. 选择类型：词库或风格。
  2. 复制模板，填写信息。
  3. 填写词条或风格说明。
  4. 存为 <id>.typeleast-plugin。
  5. 在 App 里导入测试。

模板

词库
风格

不要读音提示：删除 aliases，版本写 1。

主要字段

字段规则
id发布者.名字，小写
version例如 1.0.0，每次更新调大。
name / description中英文都要写
license例如 CC0-1.0、MIT
terms最多 2000 个词
aliases可选，读音提示
instructions风格说明，最多 8 KiB

完整规则：插件规范。

词库要点

  • 只收易错的专有名词。
  • 大小写按官方写法。
  • 每条读音提示配语境词。

风格要点

  • 只写格式和语气。
  • 越短越好。
  • 不要求输出链接或数据。

发给模型的内容

类型发送内容额外费用
词库只发相关词条不额外调用
风格每次整理都发略增 token

插件不运行代码。

提交扩展

收录到官方目录

人工审核后上线。

要求

  • 通过检查脚本。
  • 有中英文名称。
  • 许可允许再分发。
  • 不含隐私或密钥。
  • 一个插件一个用途。
  • 更新时调大版本号。

流程

  1. Fork 仓库。
  2. 放入 market/plugins/。
  3. 运行 node market/build-catalog.mjs。
  4. 提交 PR。
  5. 审核后上线。
