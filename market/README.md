# TypeLeast 风格插件目录

目录仅包含风格插件。词库与读音别名已移除，旧词库不再接受安装。格式见[插件规范](../docs/插件规范.md)。

发布流程：

1. 按规范创建 `<id>.typeleast-plugin`，放入 `plugins/`。
2. 运行 `node market/build-catalog.mjs`，验证并更新目录。
3. 提交PR，说明用途、来源与许可。维护者审查后合并，官网部署后可在应用市场看到。

更新时增加版本号。审核说明是否只涉及写法、是否夹带词汇映射或越权要求、是否有不应公开的个人和企业资料。风格不能要求添加链接、命令或联系方式，不能要求上传用户数据或忽略核心规则。

所有项目须有中英文名称和说明。市场只在用户打开或刷新时联网，不运行插件代码。测试会检查发布目录与插件源文件一致。
