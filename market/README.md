# TypeLeast 插件官方目录

App 的「插件市场」读的就是这里生成的 `catalog.json`。插件格式见 [插件规范](../docs/插件规范.md)。

## 提交一个插件

1. 按规范写一个 `.typeleast-plugin` 文件，文件名用插件的 `id`，放进 `plugins/`。
2. 在仓库根目录运行，检查并重新生成目录：
   ```bash
   node market/build-catalog.mjs
   ```
   文件不符合规范时会直接报出是哪个字段。
3. 开一个 PR，说明用途、内容来源和许可。维护者审阅内容后合并，官网部署完成后就会出现在 App 的插件市场里。

更新插件时调大 `version`，同样走 PR。

## 审阅时看什么

- 词库：词是不是真实、常用的写法，有没有人名、内部项目名这类不该公开的内容，许可是否允许再分发。
- 风格：说明是否只涉及写法和格式；不能要求模型输出链接、命令、联系方式或用户数据，不能要求忽略原有规则。
- 两种都要中英文名字和说明，作者和许可写清楚。

`service/test/market-catalog.test.js` 会检查 `catalog.json` 是否和 `plugins/` 一致、每个插件是否都能通过 App 的检查。
